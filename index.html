03 / About

Offensive experience, defensive mindset.

I'm Augustine, a cybersecurity practitioner focused on Microsoft cloud security, penetration testing and quality assurance.

I design least-privilege access in Microsoft Entra ID and Azure, test software thoroughly, and build custom tools that solve real security problems. Two penetration testing internships taught me how attackers move. Teaching CompTIA Network+ taught me to explain technical work clearly.

I hold the Certified Network Security Practitioner (CNSP) certification and a B.Sc. in Statistics from Joseph Sarwuan Tarka University, Makurdi.
