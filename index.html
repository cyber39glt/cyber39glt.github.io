CloudSecura

The challenge

A cloud security consultancy needed to audit clients' Azure subscriptions without ever being able to change them, and to hand over reports clients could trust.

A multi-tenant Entra ID app with admin consent and a custom read-only role, plus an in-app guard that blocks writes, so access is limited twice. Its own users are protected with mandatory MFA, Argon2id hashing, lockout and per-client isolation.
